# Web Performance

Site vitrine de Web Performance, réalisé en HTML, CSS et JavaScript.

## Contenu

- `index.html` : contenu et sections du site.
- `style.css` : mise en page et styles adaptatifs.
- `script.js` : menu mobile et envoi AJAX du formulaire de contact.
- `logo entreprise.png` : logo utilisé sur le site.

## Prévisualiser le site

Ouvrir `index.html` dans un navigateur. Les photos de présentation sont chargées depuis Unsplash et nécessitent une connexion Internet.

Le formulaire envoie les demandes via FormSubmit à `backertwebmaster@gmail.com`. La première soumission peut nécessiter l’activation de l’adresse par e-mail.

## Publier avec GitHub Pages

1. Créer un dépôt GitHub public nommé `web-performance`.
2. Ajouter les fichiers du site à la racine du dépôt et les envoyer sur GitHub.
3. Dans le dépôt, ouvrir **Settings → Pages**.
4. Sous **Build and deployment**, choisir **Deploy from a branch**, puis sélectionner `main` et `/ (root)`.
5. Enregistrer et attendre la publication indiquée par GitHub Pages.

Avant publication, vérifier que les coordonnées de contact et les informations affichées sont exactes.
